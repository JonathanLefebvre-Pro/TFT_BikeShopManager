## Entitées

- Auth : Entitées pour l'authentification.
- Customers : Entitées liées aux clients du magasin.
- Employees : Entitées liées aux employés, utilisateurs de l'application.
- Roles : Entitées définissant les informations de roles des utilisateurs.
- Shared : Entitées partagées par différents services.
