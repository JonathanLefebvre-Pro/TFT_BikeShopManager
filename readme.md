# 🚲 Bike Shop Manager

## 📋 Contexte

Développement d'une **API REST** complète avec authentification JWT sécurisée pour la gestion d'un magasin de vélo. L'application permet la gestion des clients, des utilisateurs avec différents rôles et la gestion du stock ainsi que des commandes.
Le client utilisant l'API est développé avec Angular.

## 🎨 Frontend

⚙️ Framework : Angular

💻 Language : Typescript
